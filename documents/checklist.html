Engineering quality

Clean code organization, sensible validation, and meaningful error handling.

  • Four layers, each in its own file: routes, validation, link logic, storage. Routes contain no logic. app/main.py, app/models.py, app/links.py, app/storage.py
  • About 500 lines across 8 app files; largest is 124 lines.
  • Every error has one shape, {"error": "field: message"}, including framework 404s. Two handlers in app/main.py.
  • Status codes chosen deliberately: 422 invalid, 409 alias taken, 404 unknown, 410 expired, 307 redirect.

Operational excellence

Observability, configurability, and scalability in a live environment.

DONE

Creation

Accept a long URL and generate a unique shortened URL.

  • POST /v1/links returns 201 with a 7-character base62 code and the full short_url.
  • Uniqueness enforced by the primary key; collisions retried up to five times. app/links.py, app/codes.py
  • Tests: test_create_returns_generated_code, test_same_url_twice_gets_different_codes.
DONE

Customization

Generated short codes or user-defined custom aliases, with appropriate validation.

  • Both supported. Optional alias in the create body.
  • Validation: 3 to 32 chars, [A-Za-z0-9_-], case-sensitive, reserved words rejected, taken alias is 409. app/codes.py
  • Tests: 12 in tests/test_alias.py, including that Docs cannot hijack /docs.
DONE

Redirection

Redirect users to the original URL when the shortened link is accessed.

  • GET /{code} returns 307 with Location. Route registered last so it cannot shadow other paths.
  • One SQL statement checks expiry, increments the count, and returns the target. app/storage.py record_hit
  • Tests: 5 in tests/test_redirect.py. Verified live, including through two containers.
DONE

Metadata & retrieval

Return metadata about the shortened URL and allow retrieval for an existing short URL.

  • Create returns the full metadata; GET /v1/links/{code} returns the same shape later: code, long URL, short URL, custom flag, hit count, created and expiry timestamps.
  • Reading metadata does not count as a hit. Test: test_metadata_does_not_count_as_hit.

Validation

Sensible error handling, input validation, and edge-case management.

  • URL: scheme, host, length, and a self-host check against redirect loops. Target is deliberately not fetched (SSRF).
  • Alias rules and reserved list. Expiry must be in the future; naive timestamps taken as UTC; offsets normalised.
  • Edge cases handled and tested: same URL twice, code collision, alias case sensitivity, deleted alias reuse, second delete, expired link not counted, old database file migrated.
